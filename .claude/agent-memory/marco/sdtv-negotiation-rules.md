# SDTV Negotiation Rules — pointer

**Canonical playbook:** `~/Projects/sdtv-festivals/negotiation-playbook.md`

## TL;DR for Marco when preparing a deal

1. **Source of truth = agreement with main organizer.** New team members don't reset scope.
2. **Never expand scope for free.** Trade extra coverage for 2-year commitment / clearer scope / better terms.
3. **After every call → written recap** (year, dates, nights/days, coverage type, exclusions, conditions).
4. **Wording:** "social dance video coverage", not "videos". Never "full coverage" unless paid + confirmed.
5. **Escalate to Кирилл before replying** if post-agreement questions touch: pricing, scope, travel, hotel, days, workshops, shows, SMM obligations.

## When to read full playbook

- Preparing arguments for a renegotiation call
- Drafting a recap email
- Building objection-handling for outbound
- Updating offer copy or pitch deck
