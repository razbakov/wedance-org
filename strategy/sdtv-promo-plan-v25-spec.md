# SDTV Promo Plan V2.5 Spec

## Goal

`V2.5` should combine:

- the clarity and confidence of the `v2` dashboard structure
- the organizer-facing sales language already implemented in `promo-plan.html`
- a restrained amount of the visual drama introduced in `v5`

The page should feel like a premium media partnership system, not a dry dashboard and not a festival poster.

## Core Principle

`V2.5 = current promo-plan sales structure + v2 skeleton + selected v5 atmosphere`

Main rule:

- do not import `v5` wholesale
- import only the parts that increase desire without reducing clarity

## Keep As-Is In Current Promo Plan

These parts of `promo-plan.html` should remain structurally intact:

- `What is already working`
- `What would make this stronger`
- `How Your Campaign Works`
- `What You Get In This Phase`
- `Why Festivals Choose SDTV`
- `Recommended Next Move`
- `The SDTV Visibility Engine`

The current page already speaks more clearly to organizers than the more experimental design variants.

## What To Transfer From V5

### 1. Hero Visual Layer

Source direction:

- `v5-desire.jsx` hero collage

Transfer:

- add one cinematic visual layer behind the current hero
- use a soft crowd silhouette
- add 2 to 3 subtle stage-light beams
- add a warm gold/red glow behind the title area
- if available, use a real SDTV-style festival still at very low opacity

Constraints:

- do not turn the hero into a full poster composition
- keep current readability of title, stage controls, and top metrics
- the hero must still feel like a product page, not a campaign flyer

### 2. Phase Mood Signals

Source direction:

- `v5-desire.jsx` phase mood panels

Transfer:

- keep the current compact stage controls
- enrich each phase with a stronger mood identity
- add a stage number such as `01 / 04`
- add one short micro-tagline
- add a tiny abstract mood-art cue inside each control
- give each phase a distinct color temperature

Constraints:

- do not replace compact controls with large poster cards
- phase switching must remain fast and product-like

### 3. Visual Proof Inside "Why Festivals Choose SDTV"

Source direction:

- `v5-desire.jsx` visual proof tiles

Transfer:

- redesign each reason card into a 2-column proof layout
- left side: small visual proof tile
- right side: title and organizer-facing explanation

Recommended proof tile types:

- audience cluster
- campaign rhythm bars
- archive frame grid
- team/coordination node map

Constraints:

- avoid generic icons
- avoid emoji
- visuals should feel editorial and abstract, not illustrative in a childish way

### 4. Engine As Premium Illustration

Source direction:

- `v5-desire.jsx` engine illustration

Transfer:

- keep current logic: `3 inputs -> SDTV core -> 4 outcomes`
- add orbit lines around the core
- add a central warm glow
- add a few floating media tiles
- turn input/output boxes into glass-like cards

Constraints:

- do not make the engine oversized or theatrical
- it must remain easy to understand in under a few seconds

### 5. CTA Polish

Source direction:

- `v5-desire.jsx` final CTA treatment

Transfer:

- make `Recommended Next Move` visually stronger
- use a restrained warm gradient or premium glow
- use one clear primary action
- keep a quieter secondary action if needed

Constraints:

- avoid loud red-banner energy
- it should feel expensive and confident, not urgent in a cheap way

## What Not To Transfer From V5

Do not bring these into `V2.5` as-is:

- full-screen poster hero treatment
- oversized phase posters
- overly dramatic red close section
- excessive glow effects
- anything that makes the page feel more like an event ad than a client proposal

## Priority Order For Implementation

### 1. Hero Pass

Why first:

- biggest perceived quality upgrade
- strongest improvement in emotional pull
- lowest risk to sales structure

### 2. Why Festivals Choose SDTV

Why second:

- adds proof and trust quickly
- most commercial value after hero

### 3. Visibility Engine

Why third:

- improves understanding of the SDTV system
- can become a signature premium block

### 4. Phase Controls / Mood Accents

Why fourth:

- helps the page feel more cohesive
- useful, but secondary to hero and trust proof

### 5. Recommended Next Move

Why fifth:

- should be polished after upper and middle sections already feel stronger

### 6. Micro Motion / Finishing

Only after the static design is right:

- subtle glow pulse
- soft hover lift
- restrained fade-in

## Working Formula

The intended final balance is:

- `v2` for structure and confidence
- current `promo-plan.html` for sales language and organizer clarity
- `v5` for selective atmosphere, proof visuals, and premium motion

## Final Test

If `V2.5` is successful, the organizer should feel all three:

- `This is clear`
- `This is premium`
- `This could make my event feel bigger, earlier, and more credible`

If the page feels only rational, it is too dry.
If the page feels only dramatic, it has gone too far.
If it does both at once, the balance is right.
