## TL;DR

SDTV = одна экосистема из 3 воронок, усиливающих друг друга.

- **B2C (танцоры)** — fast checkout. Без автоворонки. Импульсная покупка.
- **B2B (фестивали)** — classic DR autofunnel. Tier ladder: **Coverage → Media Partner → Ecosystem**.
- **B2B2C (артисты)** — DR autofunnel. Tier ladder: **Visibility Package → Tour Partner**.

**Стратегический сдвиг:** видео = основной cashflow (не убираем). Маржу системно смещаем в promo + distribution, чтобы расти без пропорционального роста выездов.

**Правило разделения:** автоворонка и email-marketing — **только B2B / B2B2C**. На B2C натягивать DR-фаннел нельзя — убьёт конверсию.

## Strategic pivot

| | Today | Target |
|---|---|---|
| Main cashflow | Видео-съёмки | Видео-съёмки (не убираем) |
| Margin growth | Pro-rata выезды | Promo + distribution пакеты |
| Dependency | On-site работа | Media leverage + distribution rights |
| Growth mode | More shoots = more revenue | Higher AOV + repeat per client |

**Rule.** Каждый год доля promo + distribution в выручке должна расти. Видео — двигатель, но не единственный рычаг.

## Three funnels

### 1. B2C — Dancers (fast checkout only)

**Pitch.** Снимаем так, чтобы танцор хотел сохранить момент — купить свой ролик/фото как личную память.

**Flow.** Видит себя в ленте/сторис → страница феста на сайте → находит своё видео → оплата → ссылка → возвращается за следующими.

**Mechanic.**
- Чистый fast checkout. Никакого opt-in перед покупкой. Никакого VSL.
- Post-purchase → мягкий email capture для возврата за следующими видео.
- Никогда не натягивать классический DR-фаннел.

**Planned.** Offline sales point на фесте (QR + реклама → витрина).

**Owners.** Kirill (video direction), Wife (photo + SMM), Kai (checkout flow + post-purchase email).

---

### 2. B2B — Festivals / Organizers (DR autofunnel)

**Pitch.** Не снимаем фестиваль — усиливаем его как бренд и продукт: контент, видимость, статус, медиа-ресурс для роста следующего издания.

**Tier ladder.**

| Tier | Что входит | Роль |
|---|---|---|
| **Coverage** | Производство медиа: фото + видео | Entry. Низкий порог. |
| **Media Partner** | Coverage + distribution через каналы SDTV | Основной продукт. |
| **Ecosystem** | Media Partner + positioning + renewal lock-in + multi-edition | High-ticket. Долгосрочка. |

Совпадает с 3-tier из master brief (Production / Production+Distribution / Production+Distribution+Positioning). Единые названия: **Coverage / Media Partner / Ecosystem**.

**Funnel mechanic.**
`opt-in page → VSL → offer page → sale → order bump → upsell → downsell`

- **VSL ирония в нашу пользу:** VSL = видео, а SDTV умеет снимать видео. Свой VSL снимаем сами, демонстрируя продукт продуктом.
- **Renewal lock-in** встраивается в Media Partner / Ecosystem: скидка при confirm следующего издания в момент оплаты текущего.

**Inbound sources.** Лента / рекомендация / возврат / CRM outreach.

**Target per client.** Не одна съёмка — годовой/ежегодный цикл.

**Owners.** Kirill (closing), Marco (offer+pricing), Kai (qualification + renewal tracking + email sequences).

---

### 3. B2B2C — Artists (DR autofunnel)

**Pitch.** Медиа-экосистема вокруг сцены: артист получает отдельный канал роста через публикации, промо и видимость на SDTV — даже без привязки к конкретному фестивалю.

**Tier ladder.**

| Tier | Что входит | Роль |
|---|---|---|
| **Visibility Package** | Promo slot + distribution window + editorial feature | Entry. Конкретные SKU, не абстракция. |
| **Tour Partner** | SDTV сопровождает артиста через серию фестов, сезонный контент | High-ticket. Операционная сложность → высокая маржа + залоченные отношения. |

**Funnel mechanic.**
`opt-in page → VSL → offer page → sale → order bump → upsell → downsell`

**Vision.** Вход через артиста ИЛИ через фестиваль → контент → распределение (fest promo / dancer shelf / artist promo) → репосты и дистрибуция → новые продажи, артисты, фестивали. **Это flywheel.**

**Owners.** Luna (content programming + VSL), Kai (artist relationships + sequences), Marco (artist offer + Tour Partner pricing).

## Cross-funnel flywheel

Апсейл должен быть не линейный (купил → купи больше), а **сетевой** — каждая продажа кормит другой funnel:

| Что происходит | Какой funnel это кормит |
|---|---|
| Dancer купил видео → данные о покупках | B2B value prop ("N танцоров купили с вашего феста") |
| Artist получил visibility на SDTV | Фестивалям нужнее иметь SDTV (pull эффект) |
| Festival coverage rights | Inventory для B2C + B2B2C |
| B2C revenue на фесте | Рычаг в renewal negotiation |

Без этого слоя — три отдельных бизнеса. С ним — одна система, где каждая воронка усиливает следующую.
