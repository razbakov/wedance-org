## Зачем

Кирилл на фестивалях снимает, а не сидит перед камерой. AI-аватар даёт контент-поток между ивентами — говорящая голова с реальным B-roll с фестивалей. Это решает главную проблему: **SDTV YouTube молчит между событиями**.

### Стартовая позиция (сильная)

- YouTube: 119K+ подписчиков
- Instagram: 510K+
- Позиционирование: "создал стандарт social dance video"
- Огромный архив реальных кадров = эксклюзивный B-roll
- McCoy набирала с нуля; у Кирилла уже есть аудитория

### Конкурентный мот

McCoy использует стоковый B-roll. У Кирилла — **эксклюзивные кадры с реальных фестивалей**, которые невозможно воспроизвести. Каждое видео уникально по умолчанию.

## Pipeline

```
Script (Claude) → Avatar (HeyGen) → Voice (ElevenLabs) → B-roll (архив SDTV) → Edit → Publish
```

### 1. Script — Claude

- Хук в первые 30 сек
- 6-8 минут value delivery
- CTA в конце
- Визуальные подсказки: где B-roll, текстовые оверлеи, переходы

### 2. Avatar — HeyGen

- Записать 2-5 мин минимум (15+ мин идеально) тренировочного видео
- Стабильный свет, один ракурс, без jump cuts
- Говорить в камеру естественно
- Чистый / нейтральный фон

### 3. Voice — ElevenLabs

- 2 часа чистого аудио без фоновых шумов
- Естественный темп, не читка
- Источники: подкасты, интервью, сторис с объяснениями, записи разговоров

### 4. B-roll — Архив SDTV

- Кадры с фестивалей (crowd energy, social dancing, shows, backstage)
- Артисты, танцоры, площадки, атмосфера
- Это главное преимущество — живой, эксклюзивный визуал

### 5. Edit

- Жена + автоматизация
- Thumbnails = реальное фото Кирилла (не аватар)

## Темы: 4 категории по бизнес-задаче

### 1. Audience Growth — для танцоров (B2C, охват)

| Тема | Формат | Бизнес-задача |
|------|--------|---------------|
| Куда ехать танцевать летом 2026 | Гид, топ-5/10 | Трафик + авторитет + Calendar продукт |
| Что делать на первом фестивале | Объяснялка для новичков | Расширение аудитории |
| Как танцевать лучше на соушелах | Разбор + вставки реальных видео | Desire + вовлечение |
| Что надеть на фестиваль | Практический гид | Pain #3 из матрицы |
| Лучшие социальные танцы недели | Еженедельный дайджест | Привычка + ретеншн |
| Этот фестиваль vs тот | Сравнение с инсайдами | Уникальная экспертиза |
| Музыка для бачаты/кизомбы/сальсы | Подборки + контекст | Музыкальный pain |

**Зачем:** решает боли из pain map (не знают куда ехать, как танцевать, что надеть). Растит аудиторию → продаёшь её организаторам.

### 2. Authority — позиционирование Кирилла (бренд)

| Тема | Формат | Бизнес-задача |
|------|--------|---------------|
| Как я снимал X фестиваль | Behind-the-scenes разбор | Proof + авторитет |
| Состояние social dance в 2026 | Аналитика + мнение | Thought leadership |
| Почему одни фестивали растут, а другие умирают | Разбор + кейсы | Авторитет для оргов |
| Что делает фестиваль великим | Инсайды, топ-признаки | Скрытый sales-контент |
| Как медиа меняет танцевальную индустрию | Манифест | Позиционирование SDTV |

**Зачем:** организаторы видят → понимают масштаб → легче продавать пакеты.

### 3. Sales Enablement — для организаторов (B2B, выручка)

| Тема | Формат | Бизнес-задача |
|------|--------|---------------|
| Как медиа влияет на продажу пассов | Кейс-стади | Прямая воронка продаж |
| 5 ошибок в промо фестивалей | Разбор | Pain-based, орги узнают себя |
| Как продвигать фестиваль в 2026 | Пошаговый гид | Authority + лид-магнит |
| Before/after: фестиваль с SDTV и без | Визуальный разбор | Social proof |

**Зачем:** органайзер видит видео → "это про меня" → заходит → квалифицируешь → продажа.

### 4. Artist Bridge — для артистов (B2B, партнёрство)

| Тема | Формат | Бизнес-задача |
|------|--------|---------------|
| Как артисту попасть на фестиваль | Разбор от инсайдера | Артисты приходят к SDTV |
| Как построить бренд танцора | Портфолио, видимость | Consulting upsell |
| Артист, которого стоит знать: [имя] | Spotlight серия | Отношения + контент |

## Пилот: 3 первых видео

1. **"Куда ехать танцевать летом 2026 — топ-10 фестивалей"** — высокий спрос, ты эксперт, много B-roll
2. **"Как я снимал [последний фестиваль] — behind the scenes"** — личный бренд + proof
3. **"Как медиа продаёт пассы: кейс SDTV"** — для оргов, скрытый sales
