## Итоговый текст на тайском (готов к отправке)

```

กล้ามเนื้อหน้าอกและหน้าอกส่วนล่างแข็ง (small chest muscle) แข็งมาก ทำให้ไหล่ดึงไปข้างหน้า
กล้ามเนื้อข้างคอ (scalene) และได้วงแขนแข็ง ทำให้ไหล่ยกและสะบักขยับไม่ดี

ช่วยโฟกัสบริเวณต่อไปนี้:
1. กล้ามเนื้อหน้าอก และหน้าอกส่วนล่างได้กระดูกในปลาจ้ำ (small chest muscle)

4. ด้านข้างทรวงอก ได้รักแร้ (serratus)

ผมอยากได้การนวดแบบดีป (deep) และการยืดแบบไทย (stretch) รวมกันนะครับ
```

## Почему именно такая комбинация

Нужно глубокое + stretch. Не просто масло/давление.

**Target зоны:**
1. Грудные + малая грудная (small chest muscle) — подтягивает плечи вперёд
2. Scalene (сторона шеи) — поднимает плечи, мешает сбалансировать лопатку
3. Subscapular (подlopatka)
4. Serratus (боковая грудь / подмышка)
5. Trapezius / rhomboid (спина, лопатка)

## Вежливые опции при записи

- "ขอมอนวดที่มีประสบการณ์ได้ด้วยนะครับ" = "прошу опытного мастера"
- Явно писать "deep + stretch" — тайцы точно знают эту комбинацию

## Что НЕ писать

- Не использовать только "relaxation massage" — будет масло, не будет проработки
- Не ограничиваться "neck & shoulders" — упустят serratus и subscapular
