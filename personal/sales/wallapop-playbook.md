# Wallapop Selling Playbook (Barcelona)

**Source:** ChatGPT chat "Стратегия продажи MacBook" (share, 2026-04-22)
**Scope:** Personal selling на Wallapop. Применимо к MacBook, другому Apple/tech, мебели.

---

## Три версии описания (использовать под ситуацию)

### A. Premium version (max price, less chats)

Структура:
1. 1 строка: что продаём + состояние + "listo para usar"
2. "Equipo ideal para X, buena experiencia de uso Y."
3. **Características principales** — bullet specs
4. 1 abzac: тон работы, комфорт (если релевант)
5. "Se entrega funcionando correctamente, con cargador, y se puede revisar en persona sin problema."
6. "Lo vendo por cambio de equipo."
7. "Barcelona, entrega en mano. No cambios."

Пример (MacBook Pro 15" 2017):
```
MacBook Pro 15" 2017 en buen estado, cuidado y listo para usar.

Equipo ideal para quien busca un portátil Apple con pantalla grande,
buena experiencia de uso y rendimiento sólido para trabajo, estudio,
oficina, gestión, contenido y multitarea.

Características principales:
• Intel Core i7 2.8 GHz
• 16 GB RAM
• Radeon Pro 555 2 GB
• macOS Ventura 13.7.8

Es un Mac muy cómodo para trabajar varias horas,
especialmente si valoras el formato de 15 pulgadas.

Se entrega funcionando correctamente, con cargador,
y se puede revisar en persona sin problema.
Lo vendo por cambio de equipo.

Barcelona, entrega en mano.
No cambios.
```

### B. Direct-sell version (faster, slightly less polish)

Короче, с bullets в начале:
- "Funciona correctamente y va muy bien para trabajo, estudio, multitarea y uso diario."
- Specs (bullets)
- "Incluye cargador. Entrega en mano en Barcelona. Precio razonable."

### C. Ultra-direct (для урезанных маркетплейсов / второй item)

Минимум текста + specs + цена + entrega.

## Frases que ayudan a convertir (добавить если правда)

- Siempre cuidado
- Sin fallos de funcionamiento
- Listo para usar
- Entrega en mano para probarlo
- Compradores serios, por favor
- No mareantes

## Frases que quitan valor — ИЗБЕГАТЬ

- ❌ "Va perfecto para edición profesional" — привлекает reclamaciones
- ❌ "Como nuevo" — если реально не impecable
- ❌ "Urgente" — снижает percepción de valor
- ❌ Demasiada historia personal

## Reply scripts

### Respuesta rápida para chat (первое касание)
```
Hola, sí, sigue disponible 😊
Está en buen estado y funciona correctamente.
Se puede ver y probar en Barcelona.
```

### Respuesta para cerrar mejor (second-touch, closing)
```
Hola, sí, sigue disponible.
Está bien cuidado, funciona correctamente y lo entrego con cargador.
Si te encaja, podemos concretar día y hora para verlo en Barcelona.
```

## Checklist перед публикацией

- [ ] Specs полный (CPU / RAM / GPU / OS / storage)
- [ ] **SSD capacity** — явно (для tech items)
- [ ] **Battery cycles + estado** (для MacBook/laptops) — сильно повышает доверие
- [ ] Estado estético — одна линия, честно
- [ ] 3-5 фото: hero, клавиатура, экран, порты, зарядник/коробка
- [ ] "Entrega en mano en Barcelona" в последней строке
- [ ] "No cambios" если не на обмен
- [ ] Причина продажи — одна строка, нейтральная ("cambio de equipo")

---

## ICP для каждого объявления

До публикации ответить на 1 вопрос: **кому это нужно?**

Примеры:
- MacBook Pro 15" 2017 → uso profesional o personal / quien busca un Mac Pro de 15" sin pagar el coste de uno nuevo
- Видео-оборудование → видеограф / студент film school
- Мебель → кто переезжает / новый в городе

ICP в тексте **не писать**, но использовать для выбора tone и bullets.
