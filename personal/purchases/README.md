## 5. Playbook (4 шага)

1. **Define constraint** — что limit: габариты / бюджет / deadline.
2. **Short-list 2-3 вариантов** — не 10, не 1.
3. **Compare по 3 критериям:** fit / cost / honest-fit-to-need.
4. **Decide + log** — записать в item-файл причину выбора.
